# Global ICT Career Database

A standalone searchable career directory containing 300 organizations, personalized for Mahmoud Salama.

## Open
Double-click `organizations.html`. No installation or web server is required.

## Included
- Search, filters, sorting and pagination
- Favorites saved in the browser
- Application status and private notes saved in the browser
- CSV export of filtered results
- JSON backup/import of your personal tracking data
- Dark/light theme
- Print / Save as PDF
- Mobile-responsive layout

## Data note
The directory was curated in July 2026. Career URLs can change. Open the linked official page and verify each vacancy, eligibility requirement, work location, remote arrangement and sponsorship condition before applying. The fit, remote and visa fields are directional indicators—not guarantees.
