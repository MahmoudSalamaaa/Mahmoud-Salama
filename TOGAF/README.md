# TOGAF Study Platform 3.0

منصة Static كاملة للمذاكرة والاختبارات تعمل دون قاعدة بيانات ودون ذكاء اصطناعي.

## التشغيل

- افتح `index.html` مباشرة لمعظم الوظائف.
- للحصول على PWA وOffline الكامل شغّل مجلد المشروع عبر خادم محلي أو GitHub Pages.
- مثال: `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## التخزين

كل الملاحظات والنتائج والبطاقات والخطط تحفظ في `localStorage` داخل المتصفح. استخدم Settings لتصدير Backup بصيغة JSON.

## الأدوات

Contextual Notes، Highlights، Bookmarks، Global Search، Practice Modes، Certification Exam، Spaced Repetition، Mastery Tree، Dynamic Planner، Question Quality Audit، Personal Glossary، Knowledge Graph، Source Reader، Cheat Sheet، PWA وAccessibility.

## المحتوى

- 47 فصلًا.
- 1246 قسمًا مفهرسًا.
- 180 سؤالًا في البنك الموحد.
- 36 Flashcards أساسية.

## الملكية الفكرية

المشروع أداة تعليمية شخصية. لا يتضمن ملف TOGAF الرسمي. استخدم نسخة مرخصة من المصدر الرسمي، وراجع شروط The Open Group قبل النشر العام.
