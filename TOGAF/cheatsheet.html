High-Risk Contrasts

  • Viewpoint = طريقة البناء؛ View = النتيجة.
  • Deliverable = مخرج تعاقدي؛ Artifact = تمثيل؛ Building Block = مكوّن قابل لإعادة الاستخدام.
  • Phase E = options/work packages؛ Phase F = priorities/detailed migration plan.
  • Phase G = governance during implementation؛ Phase H = change after/around implementation.
  • Continuum = classification؛ Repository = storage؛ Landscape = architectural coverage.
  • Governance sets direction and controls; Management executes.

Exam Rules

  • حدد الكلمة المفتاحية قبل قراءة الخيارات.
  • استبعد الخيار الصحيح عمومًا لكنه يخص Phase أخرى.
  • لا تغيّر إجابة دون سبب مفاهيمي واضح.
  • استخدم Mark for Review للأسئلة البطيئة.
  • الهدف ليس 60% فقط؛ استهدف استقرارًا أعلى من80%.
