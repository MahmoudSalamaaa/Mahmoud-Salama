# Mahmoud Salama Career & Project Intelligence — AI Edition

نسخة موحدة وقابلة للنشر من مشروع البحث عن الوظائف والجهات والمشروعات. جميع الملفات موجودة داخل مجلد `organizations` نفسه، ولا توجد Redirects إلى الـroot.

## ما الذي تم تنفيذه؟

- صفحة رئيسية موحدة لجميع قواعد البيانات والأدوات.
- بحث تقليدي سريع وبحث دلالي باللغة العربية والإنجليزية.
- تفسير تلقائي للدولة، المنطقة، القطاع، العمل عن بُعد، المستوى القيادي والاستبعادات.
- مطابقة النتائج مع ملف محمود سلامة المهني وشرح أسباب التوافق والفجوات.
- تكامل اختياري وآمن مع OpenAI من خلال Vercel Serverless API.
- Dashboard للبيانات والتوافق والمصادر وحالة التقديم.
- Application Tracker موحد مع الملاحظات والمواعيد والمتابعة ونسخ CV وCover Letter.
- مفضلة، مقارنة ثلاثية، عمليات بحث محفوظة، تنبيهات عند فتح الصفحة، سجل العناصر المشاهدة، تصدير CSV ونسخ احتياطي JSON.
- حالات منفصلة للوظائف ولأدلة الشركات والجهات.
- تصنيف موثوقية المصدر وLast Checked وLink Status.
- فاحص روابط Server-side يمنع الوصول إلى الشبكات الداخلية وMetadata endpoints.
- Data Manager محلي لإضافة سجلات شخصية ودمجها تلقائيًا في البحث.
- تصميم Responsive، دعم العربية وRTL، الوضع الداكن والفاتح، Accessibility وPWA/Offline shell.
- مصفوفة بحث ديناميكية من 25,380 تركيبة بدلاً من تكرار آلاف الأسطر داخل HTML.

## بنية البيانات

ترتيب تحميل البيانات:

1. ملفات CSV الموجودة بجانب صفحات HTML، عند نسخ المشروع فوق النسخة القديمة.
2. نسخة GitHub ثابتة عند commit `375dafd01dae682d4711deb26cb677eecc711b56`.
3. بيانات Seed مضمّنة داخل `data/seed.json`.
4. سجلات Monitoring مولّدة بوضوح للوصول إلى تغطية المشروع الأصلية دون الادعاء بوجود وظيفة محددة.

يمكن تنزيل ملفات CSV الأصلية إلى المجلد محليًا بالأمر:

```bash
npm run sync-data
```

## تشغيل سريع بدون AI خارجي

### Windows

شغّل `start-local.bat` ثم افتح:

```text
http://localhost:8080/index.html
```

### macOS / Linux

```bash
./start-local.sh
```

البحث الدلالي المحلي، الفلاتر، Dashboard، المفضلة والمتابعة تعمل بدون API key. فحص الروابط والـAI السحابي يحتاجان تشغيل Vercel.

## النشر على Vercel

1. ارفع مجلد `organizations` كما هو، أو اجعل **Root Directory** في Vercel هو `organizations`.
2. شغّل التثبيت العادي باستخدام `npm install`.
3. أضف Environment Variables:

```text
OPENAI_API_KEY=your_server_side_key
OPENAI_MODEL=gpt-5-mini
```

4. انشر المشروع.

مفتاح OpenAI لا يوضع نهائيًا داخل `assets/*.js` أو HTML. ملف `.env.example` مجرد نموذج ولا يحتوي على مفتاح حقيقي.

## وضع AI

- **Local semantic mode:** يعمل دائمًا في المتصفح، دون إرسال البيانات للخارج.
- **Cloud reranking:** يرسل السؤال وأفضل 50 نتيجة مرشحة فقط إلى `/api/ai-search` لإعادة ترتيبها.
- لا يتم إرسال ملف CV إلى OpenAI.
- الـAPI ملزم بإرجاع IDs موجودة في القائمة فقط، لمنع اختلاق وظائف أو جهات جديدة.

## فحص المشروع

```bash
npm run validate
```

يتحقق من الملفات الأساسية، بيانات Seed، صفحات HTML، وعدد عناصر مصفوفة البحث.

## تحديث البيانات

- حدّث CSV المناسب مع الحفاظ على الأعمدة القياسية:

```text
id,title,subtitle,type,region,country,location,fit,status,posted,checked,notes,source,url
```

- استخدم `checked` بصيغة `YYYY-MM-DD`.
- الوظيفة المسماة التي لم يتم التأكد من استمرارها يجب أن تكون `Needs Verification`، لا `Open`.
- البحث الحي أو صفحة الوظائف العامة يجب أن تكون `Monitoring`.

## الخصوصية

بيانات المتابعة والمفضلة وعمليات البحث المحفوظة تبقى في `localStorage` على جهاز المستخدم. يمكن تصديرها يدويًا كنسخة JSON ثم استيرادها على جهاز آخر.
