# Status Mapping and UX Rules

## Visual priority

The card color represents the status that most strongly affects the user's next action:

1. **Offer**
2. **Application progress**: Interview, Applied, Shortlisted
3. **Action required**: Follow-up, Deadline Approaching
4. **Terminal outcome**: Rejected, Withdrawn, Not Suitable, Not Available
5. **Source availability**
6. **Neutral / unverified**

## Mapping

### Green — Available
- Available
- Career Page Available
- Active Employer
- Active Agency
- Active Portal
- Active Platform
- Live Search

### Blue — In progress
- Saved
- Interested
- Shortlisted
- Applied
- Interview

### Amber — Attention
- Possibly Available
- Deadline Approaching
- Follow-up

### Red — Unavailable
- Expired
- Not Available
- Inactive
- Broken Link
- Rejected
- Withdrawn
- Not Suitable

### Purple — Offer
- Offer

### Gray — Neutral
- Not Verified
- Not Reviewed
- Ignored
- Any unknown value

## Accessibility

- Color is paired with a written label.
- Cards use a border rail and a subtle tint rather than a solid saturated fill.
- Controls are at least 44px high.
- Keyboard focus is visible.
- Dark mode has dedicated contrast values.
- High-contrast and reduced-motion user preferences are supported.
