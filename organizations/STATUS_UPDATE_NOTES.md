# Not Available Status Update

Version 4.1 adds a personal status named **Not Available**.

Meaning: the user opened the careers page and found no vacancy suitable for them at that time. This is separate from link health and from the organization's general recruitment activity.

Implemented in:
- result cards as a quick status selector
- record details / tracking form
- application tracker columns and summary count
- table view
- bilingual English/Arabic guidance
- browser backup/export data

The date of marking Not Available is saved automatically in local storage.
