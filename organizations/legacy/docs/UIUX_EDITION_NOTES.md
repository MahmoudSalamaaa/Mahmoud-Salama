# UI/UX Edition Notes

## Information architecture

- Main navigation: Home, Explore, Africa NGOs, Jobs, Organizations, My Applications.
- Secondary sections are grouped under More.
- AI search, cloud reranking, saved-search alerts and related API configuration were removed.
- Explore provides transparent keyword search with category, country, type, region, status and fit filters.

## Visual system

- Professional navy navigation with blue and teal primary accents.
- Light mode by default and a fully supported dark mode.
- Consistent border radii, spacing, typography and elevation.
- Clear semantic colors for open, monitoring, verification and unavailable states.
- Larger touch targets and visible keyboard focus states.

## Africa organizations

- Africa NGOs remains a primary navigation item and a featured homepage destination.
- The directory contains 148 named organizations and official website or career links.
- ReliefWeb, Devex and Impactpool remain available as quick external discovery sources.

## Accessibility and responsive behavior

- Skip link, semantic navigation, aria labels and visible focus states.
- Minimum 44px interactive controls.
- Responsive layouts for desktop, tablet and mobile.
- Reduced-motion support and print-friendly styles.
