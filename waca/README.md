# MSF WaCA Information System Manager Interview Project

## Open
Open `index.html` in any modern browser. The project is fully static and works offline.

## Included
- Role analysis based on the actual 2026 WaCA vacancy
- 118 bilingual interview questions: 59 supplied + 44 vacancy-specific + 15 AWS/written-exam additions
- Revised model answers where the original wording overreached or was too generic
- Search, filters, progress status and private browser notes
- Timed mock interview and scoring
- STAR answer builder
- MSF systems confidence map with explicit AWS evidence levels
- 30-60-90 day plan

## Data and privacy
Progress and notes are stored only in the browser's localStorage. No information is sent anywhere.

## Important preparation issue
The job posting requires professional French and English. The project provides an honest answer strategy but does not replace language proficiency.

The original DOCX is retained under `source/`.
