# Research basis

Public sources reviewed in August 2026:

1. MSF WaCA Information System Manager (re-opening) vacancy archive — Impactpool.
2. MSF International Reference Field Function Grid — Information Systems Specialist.
3. MSF Intersectional Evaluation Group — public description of Shared IT Services (SITS).
4. Evaluation of the MSF WaCA Strategic Plan 2021–2025, published 19 November 2025.
5. MSF public glossary and evaluation material referencing UniField and DHIS2.
6. MSF REACH evaluation annexes documenting AWS security, backup retention and cross-region backup recommendations.
7. Candidate evidence: AWS was included in the written selection examination. This is treated as a strong WaCA-specific signal, not public confirmation of the production architecture.

## Confidence rule used in this project
- **Confirmed:** stated in the WaCA vacancy.
- **Public MSF-wide evidence:** documented somewhere in the MSF movement, but not confirmed for WaCA.
- **Written-exam signal:** highly relevant to WaCA selection, but not sufficient to claim the exact production architecture.
- **Verify:** should be asked in interview and must not be presented as fact.
